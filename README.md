## 🔬 Current Project — StatFlow

**StatFlow** is a human-in-the-loop statistical analysis platform designed to guide users through structured statistical workflows while maintaining transparency and user control.

The platform combines:

* Python & FastAPI backend
* React frontend
* Statistical analysis and workflow guidance
* AI-assisted statistical interpretation
* Local LLM integration using Ollama
* DeepSeek and Qwen model evaluation
* Prompt and context engineering
* LLM provider abstraction and API architecture
* Model reliability and response-time evaluation

A major focus of the project is exploring how LLMs can assist statistical analysis **without replacing deterministic statistical computation or user decision-making**.

➡️ [View StatFlow](https://github.com/satpsg/statflow)
